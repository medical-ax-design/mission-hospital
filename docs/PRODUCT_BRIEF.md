# Wait:ON 보호자 동행 서비스 제품 개요

## 1. 문서 정보

- 제품명: **Wait:ON**
- 문서 상태: 4일 발표용 프로토타입 기준
- 제품 유형: 병원용 B2B2C 환자·보호자 경험 지원 서비스
- 현재 시나리오: 68세 위암 수술 환자의 보호자 여정

## 2. 한 줄 정의

치료를 기다리는 보호자에게 병원이 확인한 진행 상태와 지금 해야 할 일을 연결해, 불확실성과 병원 이용 혼란을 줄이는 서비스다.

## 3. 발견한 문제

현장 인터뷰에서 보호자는 치료 자체뿐 아니라 기다리는 동안 다음 문제를 함께 겪고 있었다.

- 치료가 어느 단계인지, 다음 안내가 언제 오는지 알기 어렵다.
- 번호표가 필요한 키오스크와 바로 이용할 수 있는 키오스크가 구분되지 않는다.
- 서류 발급, 수납, 대리처방을 어디서 처리하는지 오래 다닌 사람만 안다.
- 환자가 치료 중일 때 보호자가 처리할 업무와 이동 순서를 한 화면에서 보기 어렵다.
- 짧은 진료 시간에 들은 설명을 이해하고 다른 가족에게 다시 전달하기 어렵다.
- 병원의 실제 확인 정보와 일반적인 치료 설명이 섞이면 오해할 위험이 있다.

## 4. 핵심 사용자

### 1차 사용자: 장시간 대기하는 보호자

특히 암 수술·항암 치료 환자를 동행하고, 환자가 치료 중인 동안 행정업무와 가족 연락을 담당하는 보호자다.

### 2차 사용자: 고령 환자

큰 글씨, 최소 입력, 현재 행동 하나 중심의 안내를 보호자와 함께 사용한다.

### 제품 구매·운영 사용자: 병원 환자경험 및 원무 조직

공식 안내의 정확도와 운영 효율을 관리하고 반복 길 안내·진행 문의를 줄이려는 조직이다.

## 5. 가치 제안

| 순간 | 기존 불편 | Wait:ON의 역할 |
|---|---|---|
| 치료 대기 | 현재 상황을 몰라 불안함 | 병원이 확인한 단계와 다음 안내 표시 |
| 보호자 업무 | 처리 장소와 절차를 여러 번 질문 | 목적, 현재 위치, 키오스크·창구, 순서 연결 |
| 병원 이동 | 오래 다닌 사람의 경험에 의존 | 병원이 승인한 이용 방법을 공식 가이드로 제공 |
| 진료 후 | 설명을 기억·전달하기 어려움 | 의료진 확인 내용만 쉬운 구조로 정리 |

## 6. 제품 원칙

1. **확인된 사실을 먼저 보여준다.** 예상 종료시각이나 환자 상태를 추측하지 않는다.
2. **지금 할 일 하나를 우선한다.** 전체 메뉴보다 현재 행동을 크게 보여준다.
3. **상태와 교육을 분리한다.** 실제 확인 단계와 일반적인 수술 과정의 출처를 구분한다.
4. **목적부터 묻는다.** 건물 탐색보다 “서류 발급” 같은 이용 목적에서 경로를 시작한다.
5. **AI보다 승인 흐름이 우선이다.** 의료진 확인 전에는 요약을 생성하지 않는다.
6. **고령 사용자와 보호자가 함께 쓴다.** 44px 이상 조작 영역, 쉬운 문장, 최소 입력을 기본으로 한다.

## 7. 현재 프로토타입

하나의 가상 보호자 여정을 끝까지 시연한다.

```text
환자 연결
→ 치료 진행 확인
→ 일반 과정 이해
→ 보호자 업무 확인
→ 목적 기반 이동
→ 업무 완료
→ 의료진 확인 설명
→ 가족 공유 미리보기
```

발표자 도구는 실제 사용 기능이 아니라 `?demo=1`에서만 보이는 상태 전환 장치다.

## 8. 안전 경계

이 프로토타입의 치료 단계, 이동 경로와 의료진 설명은 모두 가상 데이터이며 실제 환자 상태 또는 의료지침이 아니다.

- 실제 환자정보를 저장하지 않는다.
- 실제 삼성서울병원 실내지도나 업무 절차라고 주장하지 않는다.
- EMR·OCS·Voice EMR과 연결하지 않는다.
- AI가 진단, 복약, 주의사항 또는 의료지침을 생성하지 않는다.
- 가족 공유 버튼은 실제 메시지를 전송하지 않는다.

## 9. 인접 제품 트랙

검사·수술 준비 누락 방지 서비스는 병원 승인 프로토콜, 환자 준비 작업, 의료진 예외 대시보드를 중심으로 한 별도 후속 트랙이다. 관련 도메인·DB·인프라 문서는 장기 설계 자산으로 유지하지만, 이번 보호자 모바일 UI의 구현 범위는 아니다.

## 10. 검증할 가설

- 보호자가 첫 화면에서 10초 이내에 현재 치료 단계와 지금 할 일을 말할 수 있는가?
- 길 안내 없이도 서류 발급 장소, 번호표 필요 여부, 이동 순서를 설명할 수 있는가?
- 실제 상태와 일반 교육 정보를 구분할 수 있는가?
- 확인 전 요약을 보여주지 않는 정책을 신뢰할 수 있는가?
- 40대 이상 보호자와 고령 환자가 별도 교육 없이 주요 버튼을 사용할 수 있는가?

임상 결과 개선, 문의량 감소 또는 비용 절감은 이번 프로토타입으로 입증하지 않는다.
