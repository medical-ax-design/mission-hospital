# 검사·수술 준비 누락 방지 서비스 제품 개요

## 1. 문서 정보

- 제품명: **Ready:ON**(MVP 가칭)
- 문서 상태: 승인된 초기 제품 정의
- 대상 릴리스: 4일 발표용 프로토타입
- 제품 유형: 병원용 B2B2C 준비 오케스트레이션 서비스

## 2. 한 줄 정의

병원이 승인한 검사·수술 준비사항을 환자와 보호자가 제때 수행하도록 돕고, 의료진에게는 준비가 완료되지 않은 환자만 선별해 보여주는 서비스다.

## 3. 해결하려는 문제

검사와 수술은 금식, 약물 조정, 장정결, 보호자 동행, 준비물, 도착 시각 등 여러 사전 조건을 가진다. 안내가 종이, 문자, 앱, 전화와 진료실 설명에 분산되면 다음 문제가 생긴다.

- 환자가 지금 해야 할 일을 판단하기 어렵다.
- 고령 환자가 긴 안내문과 복잡한 앱 탐색을 부담스러워한다.
- 보호자가 준비 상태를 알지 못해 적절한 시점에 돕기 어렵다.
- 의료진이 검사 직전에 누락을 발견해 반복 확인과 재안내를 수행한다.
- 병원마다, 검사마다, 조영제 사용 여부마다 지침이 달라 일반화된 안내가 위험하다.
- 안내문이 변경된 뒤 어떤 환자에게 어떤 버전이 전달됐는지 확인하기 어렵다.

## 4. 제품 원칙

### 병원 승인 정보만 전달한다

서비스는 의료지침을 생성하거나 판단하지 않는다. 병원이 등록하고 승인한 프로토콜만 환자에게 전달한다.

### 지금 할 일 하나를 명확하게 보여준다

환자 화면은 전체 준비과정을 한 번에 요구하지 않는다. 현재 시점에 필요한 행동과 완료 방법을 우선한다.

### 보호자는 보조자다

환자는 보호자에게 도움을 요청할 수 있고, 보호자는 환자의 동의 범위 안에서 준비 상태를 확인한다.

### 의료진은 예외에 집중한다

기본 화면은 모든 환자 목록이 아니라 미확인, 지연, 도움 요청, 의료진 확인 필요 상태를 우선한다.

### 배포된 안내는 추적 가능해야 한다

게시된 프로토콜은 수정하지 않는다. 새 버전을 만들고, 환자에게 배정된 안내는 스냅샷으로 보존한다.

## 5. 주요 사용자

### 프로토콜 관리자

- 검사·수술 항목을 등록한다.
- 준비 프로토콜을 작성하고 버전을 관리한다.
- 승인된 버전을 게시 또는 종료한다.

### 의료진

- 예정 환자의 준비 상태를 확인한다.
- 도움 요청과 확인 필요 항목에 대응한다.
- 필요한 경우 환자 준비 케이스를 생성한다.

### 환자

- 현재 해야 할 일을 확인한다.
- 완료, 어려움 또는 의료진 확인 필요 상태를 전달한다.
- 큰 글씨와 최소 입력으로 이용한다.

### 보호자

- 환자의 명시적 연결 이후 준비 상태를 확인한다.
- 환자의 도움 요청을 받고 전화 또는 설명으로 지원한다.

## 6. 핵심 가치

| 사용자 | 제공 가치 |
|---|---|
| 환자 | 긴 안내문을 해석하지 않고 지금 해야 할 일을 확인 |
| 보호자 | 필요한 시점에 환자를 지원하고 준비 누락을 함께 예방 |
| 의료진 | 전체 환자에게 반복 전화하지 않고 예외 환자에 집중 |
| 병원 | 승인된 안내의 버전, 적용, 확인 이력을 관리 |

## 7. 성공 가설

병원이 승인한 준비사항을 시간순 작업으로 바꾸고 환자·보호자·의료진이 같은 상태를 공유하면 다음 결과가 나타날 수 있다.

- 검사·수술 전 확인되지 않은 준비항목이 조기에 드러난다.
- 환자의 안내 이해도와 준비 완료율이 높아진다.
- 의료진의 반복 확인 업무가 줄어든다.
- 준비 미흡으로 인한 당일 지연 가능성을 더 일찍 발견한다.

초기 프로토타입은 임상 효과나 취소율 감소를 입증하지 않는다. 제품 흐름과 정보 전달 가능성을 검증한다.

## 8. 비목표

- 진단, 치료 또는 복약 결정을 제공하지 않는다.
- 환자의 응답만으로 검사 가능 여부를 판정하지 않는다.
- AI가 병원 지침을 작성하거나 자동 승인하지 않는다.
- 실제 삼성서울병원 EMR·OCS와 연동하지 않는다.
- 실제 환자 개인정보를 저장하지 않는다.
- 보험청구 또는 보험약관 분석을 포함하지 않는다.
- 병원 운영 게임이나 대기시간 예측 기능을 포함하지 않는다.

## 9. 공개 근거의 사용 원칙

공식 병원 웹사이트에 공개된 검사·수술 안내는 프로토타입 콘텐츠 참고자료로 사용할 수 있다. 실제 운영 지침의 원본으로 간주하지 않으며, 생산 환경에서는 해당 병원이 제공한 최신 승인 문서를 기준으로 한다.

같은 CT라도 비조영, 조영, 검사 부위에 따라 금식 조건이 달라질 수 있다. 따라서 검사명을 기준으로 하나의 일반 규칙을 만들지 않는다.

## 10. 장기 확장

- 병원 EMR·OCS 처방 코드 연동
- HL7/FHIR 기반 검사·수술 일정 수신
- 병원별 프로토콜 테넌트 분리
- 환자 앱·문자·카카오 알림 연동
- 다국어 및 읽어주기
- 환자별 위험조건에 따른 의료진 확인 분기
- 준비 누락 유형과 대응시간 분석
