# Wait:ON 아트 및 모션 가이드

## 문서 정보

- 상위 문서: [`PROJECT_V2.md`](./PROJECT_V2.md)
- UX 기준: [`UX_FLOW.md`](./UX_FLOW.md)
- 문서 목적: 병원 단면, 캐릭터, 조명, 시각 효과, 카메라와 에셋 제작 원칙을 정의한다.

---

## 1. 아트 목표

Wait:ON의 화면은 다음 인상을 전달한다.

- 병원이라는 장소를 알아볼 수 있음
- 무섭거나 차갑지 않음
- 운영 상태를 빠르게 읽을 수 있음
- 밝지만 과도하게 장난스럽지 않음
- 환자와 의료진을 존중함
- 작은 모바일 화면에서도 구분됨

### 키워드

- 신뢰감
- 친근함
- 차분함
- 단순함
- 따뜻한 낮빛
- 기능적인 애니메이션

---

## 2. 비주얼 형식

### MVP

- 세로형 2D 병원 단면
- 단순화된 벡터 또는 저해상도 스프라이트
- 정면 또는 약한 아이소메트릭 시점
- 부서별 큰 형태와 이름판
- 환자와 의료진은 역할을 식별할 수 있는 작은 캐릭터

### 피해야 할 형식

- 사실적인 수술 장면
- 혈액, 상처, 고통을 강조한 표현
- 지나치게 사실적인 응급실 연출
- 실제 병원 로고와 유니폼의 무단 복제
- 환자를 장애물이나 불평하는 적으로 표현

---

## 3. 병원 단면

### MVP 공간

```text
상단층: 외래 · 검사실
하단층: 응급실 · 수술실
공용 바: 병상 현황
```

각 부서는 멀리서도 구분되는 랜드마크를 가진다.

| 부서 | 랜드마크 |
|---|---|
| 외래 | 접수 번호판과 대기 의자 |
| 검사실 | 원형 검사 장비와 상태등 |
| 응급실 | 십자 표식이 아닌 `응급` 텍스트와 처치 공간 아이콘 |
| 수술실 | 수술 일정판과 문 위 상태 표시 |
| 병상 | 1·2·6인실을 나타내는 침대 수 아이콘 |

적십자 표장처럼 사용이 제한될 수 있는 실제 의료 표식을 임의로 사용하지 않는다.

---

## 4. 색상

### 기본 역할

- 배경: 따뜻한 회백색
- 구조물: 낮은 채도의 청록·파랑
- 환자 경험 정보: 부드러운 청색
- 일정 주의: 황색 계열과 아이콘
- 운영 위험: 낮은 채도의 적색과 명확한 텍스트
- 완료: 녹색 계열과 체크 아이콘

### 원칙

- 색상 하나로 상태를 전달하지 않는다.
- 위험도는 색, 아이콘, 숫자와 텍스트를 함께 사용한다.
- 밝은 발광 효과는 어두운 배경판이나 외곽선과 함께 사용한다.
- 환자 안전 경고를 공포를 유발하는 강한 적색 화면으로 표현하지 않는다.

---

## 5. 시간대와 환경

병원 창문 밖 하늘과 실내 조명으로 하루 진행을 보여준다.

| 시간대 | 환경 |
|---|---|
| 오전 | 밝고 낮은 채도의 푸른 하늘 |
| 낮 | 가장 밝은 자연광 |
| 오후 | 약한 노란빛 |
| 하루 종료 | 따뜻한 주황빛과 낮아진 채도 |

### MVP

- CSS 그라데이션 하늘
- 2~3개의 구름 레이어를 낮은 속도로 이동
- 시간대 사이를 부드럽게 보간
- 실내 조명은 밝기와 색온도만 변경

### 후속

- 절차적 구름
- 날씨 변화
- 부서 조명과 외부 환경의 연동

3D 스카이박스와 실시간 Worley·Perlin 노이즈 계산은 MVP에서 사용하지 않는다.

---

## 6. 조명과 노멀 맵

### MVP

- 고정된 그림자
- CSS 또는 SVG 그라데이션
- 선택된 부서의 약한 외곽 발광
- 장비 작동 상태등

### 후속

- 주요 배경과 대형 시설에만 2D 노멀 맵 적용
- 시간대 조명에 따라 표면 밝기 변화
- WebGL 렌더러를 도입할 가치가 검증된 경우에만 사용

모든 캐릭터와 오브젝트에 노멀 맵을 만드는 것은 제작비와 모바일 성능 대비 효과가 낮아 제외한다.

---

## 7. 블렌딩과 시각 효과

### 가산·스크린 계열

- 검사 장비 작동
- 처리 완료
- 선택된 부서
- 시간대 조명

### 곱하기 계열

- 구조물 그림자
- 비활성 공간
- 일시정지 배경

### 알파 블렌딩

- 이벤트 패널 뒤 배경
- 정보 카드
- 환자 이동 경로

### 제한

- 화면 전체 발광 금지
- 반복 점멸 금지
- 여러 발광 효과 동시 중첩 제한
- 3회/초 이상의 빠른 명멸 금지
- 위험 이벤트를 섬광으로 알리지 않음

---

## 8. 캐릭터

### 표현 원칙

- 환자와 의료진 모두 개별 인격을 가진 사람으로 표현한다.
- 나이, 성별, 장애, 문화적 배경을 하나의 성격이나 행동과 고정 연결하지 않는다.
- 의료진 피로를 게으름이나 무능함으로 표현하지 않는다.
- 환자 불만을 우스운 방해 요소로 만들지 않는다.
- 심각한 고통과 공포 표정을 반복 연출하지 않는다.

### 상태 표현

| 상태 | 표현 |
|---|---|
| 대기 | 의자, 번호표, 잔잔한 호흡 |
| 안내 필요 | 말풍선과 정보 아이콘 |
| 이동 | 짧은 걷기 애니메이션 |
| 처리 중 | 부서 활동 아이콘 |
| 완료 | 체크와 안도하는 표정 |
| 의료진 피로 | 속도 저하와 휴식 아이콘 |

---

## 9. 카메라와 모션

### 카메라

- 병원 전체 화면은 고정한다.
- 부서 선택 시 0.25~0.4초 확대
- 수평 이동보다 수직 이동을 더 느리게 하지 않고 동일한 짧은 전환을 사용한다.
- 환자 캐릭터를 연속 추적하지 않는다.
- 카메라 흔들림은 사용하지 않는다.

### 모션

- 기능을 설명하는 움직임만 사용한다.
- 상태 변화는 0.15~0.4초 안에 전달한다.
- 반복 장식 애니메이션은 낮은 빈도로 사용한다.
- 모션 줄이기 설정에서는 즉시 전환한다.

자유 카메라가 필요한 후속 버전에서는 작은 이동을 무시하는 데드존과 부드러운 보간을 사용한다.

---

## 10. UI 효과

### 이벤트 강조

- 해당 부서 테두리
- 상태 아이콘
- 한 번의 짧은 밝기 변화
- 이벤트 제목 배지

### 처리 완료

- 체크 아이콘
- 0.3초 이하의 약한 발광
- 숫자 변화
- 원인 메시지

### 차단

- 카드의 짧은 흔들림
- 잠금 아이콘
- 한 줄 차단 이유
- 가능한 대안

효과는 상태를 설명해야 하며 장식만을 위해 사용하지 않는다.

---

## 11. 사운드

- 무음 상태를 완전 지원한다.
- 배경음은 낮은 밀도와 반복 피로도가 낮은 곡을 사용한다.
- 정점 단계에서도 전투 음악처럼 위협적으로 만들지 않는다.
- 이벤트는 짧은 알림음 하나로 표시한다.
- 완료음과 경고음의 음색을 구분한다.
- 진료 호출과 혼동될 수 있는 방송음·벨소리를 사용하지 않는다.

---

## 12. 에셋 제작 순서

1. 사각형, 텍스트와 임시 아이콘으로 게임 루프 검증
2. 병원 단면 레이아웃 확정
3. 오픈 라이선스 아이콘 또는 임시 SVG 적용
4. 플레이테스트로 정보 구분 검증
5. 최종 캐릭터와 시설 제작
6. 조명과 효과 추가
7. 후속 버전에서 노멀 맵과 고급 환경 연출 검토

완성된 게임 루프보다 스프라이트 제작을 먼저 진행하지 않는다.

---

## 13. 에셋 관리

모든 외부 에셋은 다음 정보를 기록한다.

- 파일명
- 원본 URL
- 제작자
- 라이선스
- 수정 여부
- 사용 위치

출처나 상업적 사용 가능 여부가 불명확한 에셋은 사용하지 않는다. 참고 게임의 화면, 캐릭터와 고유 UI를 복제하지 않는다.

---

## 14. 아트 수용 기준

1. 축소된 병원 전체 화면에서 네 부서를 구분할 수 있다.
2. 색상을 제거해도 핵심 상태를 아이콘과 텍스트로 구분한다.
3. 이벤트 대상 부서를 3초 안에 찾을 수 있다.
4. 무음과 모션 줄이기 상태에서도 모든 핵심 피드백을 이해한다.
5. 공포, 상처, 수술 실패를 시각적 보상이나 실패 연출로 사용하지 않는다.
6. 시간대 변화가 게임 진행을 방해하지 않고 하루 흐름을 전달한다.
7. 외부 에셋의 출처와 라이선스가 기록된다.
