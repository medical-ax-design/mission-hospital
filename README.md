# Wait:ON 보호자 동행 프로토타입

Wait:ON은 환자의 보호자가 병원 이용 전후에 **확인된 치료 단계**, **지금 처리할 업무**, **목적에 맞는 이동 안내**, **공식 검사 준비 제한**을 하나의 여정으로 이어서 보는 Medical AX 서비스 프로토타입입니다.

현재 구현은 4일 발표용 가상 위암 수술 여정과 건강검진 오전 대장내시경 준비 여정입니다. 기존에 설계한 전체 검사·수술 준비 누락 방지 오케스트레이션은 후속 제품 트랙으로 문서에 보존하며, 이번 UI에 모두 구현된 것으로 간주하지 않습니다.

> 치료 단계와 일정은 가상 데이터다. 원내 지도와 시설 위치는
> 삼성서울병원 현재 공식 공개자료를 사용한다. 공식 지도에서
> 출발지·복도·동일 승강기·도착지를 모두 대조한 한 경로만
> `OFFICIAL_PUBLIC`으로 제공하며, 나머지는 임의의 선을 표시하지 않는다.

## 구현된 발표 여정

1. 가상 환자 김정우(68세, 위암 수술)를 보호자 김서연(딸)과 연결
2. 병원이 확인한 치료 진행 단계와 다음 안내 확인
3. 일반적인 수술 과정을 별도 교육 정보로 확인
4. 보호자 업무에서 삼성서울병원 공식 서류 발급 방법 확인
5. 온라인·모바일·병원 방문 방법과 공식 원무 위치 확인
6. 본관·별관·암병원·양성자치료센터 전체 층 안내 탐색
7. 공식 층 안내도와 시설번호 확인
8. 암병원 3층 수술환자가족대기실에서 2층 원무수납까지 층별 경로 확인
9. 확인되지 않은 나머지 목적지는 경로선 없이 원문과 안내 데스크 확인
10. 발표자 도구로 치료 단계 전환

두 번째 발표 여정에서는 가상 환자 박영희(67세, 건강검진 오전
대장내시경)를 선택해 현재 단계의 공식 제한을 확인하고 음식·행동을
검색한다. 공개 안내로 판단할 수 없는 항목은 의료진 질문으로 저장,
완료 또는 삭제할 수 있다. 절대 금식은 삼성서울병원 공개 안내에 따라
검사 당일 오전 5시부터로 표시한다.

## 로컬 실행

Node.js 22 이상과 npm이 필요합니다.

```bash
npm install
```

터미널 1:

```bash
npm run dev --workspace @ready-on/api
```

터미널 2:

```bash
NEXT_PUBLIC_API_BASE_URL=http://localhost:3001 npm run dev --workspace @ready-on/web
```

- 일반 화면: `http://localhost:3000`
- 발표자 도구 포함: `http://localhost:3000/?demo=1`
- API 상태: `http://localhost:3001/health/ready`

메모리 저장소를 사용하므로 API 프로세스를 재시작하면 가상 여정은 초기화됩니다.

## 기술 구성

- Web: Next.js 16, React 19, TypeScript
- API: NestJS 11, TypeScript
- 계약 검증: Zod
- 테스트: Vitest, Testing Library, Supertest
- 후속 운영 인프라 후보: Vercel, OCI, Supabase PostgreSQL

## 안전 경계

- 실제 환자정보, 병원 내부 경로 그래프, EMR·OCS 또는 Voice EMR을 연결하지 않습니다.
- 교육용 일반 과정과 병원이 확인한 치료 상태를 화면에서 구분합니다.
- AI가 진단, 의료지침 또는 진료 요약을 새로 만들지 않습니다.
- 공개 안내도에서 출발지·복도·동일 승강기·도착지가 모두 대조된
  경로만 공식 지도 기반 경로로 표시합니다.
- 병원 승인 경로와 공식 공개지도 좌표화 경로를 출처 상태로 구분합니다.
